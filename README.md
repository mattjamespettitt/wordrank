# Word Rank

Website for the Word Rank iPhone apps (French Word Rank): privacy policy, support page and the
open word list. Published with GitHub Pages.

The word data in `data/` is adapted from [Lexique 3.83](http://www.lexique.org) and licensed
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The pages themselves are © Matt Pettitt.
